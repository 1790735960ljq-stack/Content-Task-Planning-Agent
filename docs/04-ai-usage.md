# AI 使用记录

## 使用范围

使用 Cursor 中的 AI 助手完成本项目的方案讨论、代码、测试、运行记录和文档。

助手参与的内容：

- 把考核规则整理成可实现的边界：ReAct 循环、执行骨架、任务状态和交付物
- 选择 `langchain.agents.create_agent`，并说明它不负责费用账本和失败留痕
- 编写 `src/`、`tests/`、`data/`、`examples/` 的生成命令和 `docs/`
- 根据第一次真实运行结果核对验收路径

## 个人确认和修改

题目选定为内容任务规划 Agent。运行方式确认为一次命令、一份 JSON，不做前端。模型配置使用本地 `.env` 中的阿里云兼容接口，密钥不进入仓库。

方案讨论中确认了三件实现约束，并写进代码：

- 超预算后的下一步由模型发出，不在 Python 里写死改选精简方案
- 任务状态独立于 LangChain 的 `messages`
- 工具失败只返回观察结果，不在工具内部自动重试

第一次 live 运行已经出现“估算 12 后改选精简方案”的 Trace，提示词保持 `skeleton-v1`，没有为了通过用例再加硬编码分支。

## 验证

- `pytest`：18 项通过，不访问真实模型
- live 记录：正常完成、工具失败、预算 10 改选 8、预算 5 不可行、同一输入执行两次
- 缺预算和缺截止时间的记录确认工具调用次数为 0
- 检查 `examples/` 和文档，确认没有写入密钥或接口地址

Mock 的步数上限记录只用于展示未完成状态，不作为模型决策证据。
